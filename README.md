# たすひくチャレンジ

1年生のたし算・ひき算を練習するアプリです（1ファイル・オフライン対応）。

- レベル1：5のごうせい（例：2と□で5）
- レベル2：10のごうせい（例：1と□で10）
- レベル3：くりあがりのないたし算（和が10以下）
- レベル4：くりさがりのないひき算（10以下の数）
- レベル5：くりあがりのあるたし算（和が20以下）
- レベル6：くりさがりのあるひき算（20以下の数）

モードは「れんしゅう → チャレンジ → ぼうけん」の順にレベルアップします。

## ① れんしゅうモード
- 5問。問題に合わせて玉を置いたそろばんを使って考えられる（左に寄せた玉を数える）
  - レベル1：5玉そろばん。「2と□で5」なら左に2玉・右に3玉
  - レベル2：10玉。「1と□で10」なら左に1玉・右に9玉
  - レベル3：必要な玉だけ。「2＋3」なら左に2玉・右に3玉 → 右の玉を左へ
  - レベル4：必要な玉だけ。「8－3」なら左に8玉 → ひく数だけ右へ
  - レベル5：20玉の枠。「8＋5」なら上段に8玉、枠の外にバラ5玉。「あといくつで10？」→ バラを上段へスワイプして10を作り、残りを下段へ
  - レベル6：20玉の枠。「13－4」なら上段に10玉・下段に3玉。「10からひこう」→ 上段の玉を右へスワイプして消し、残りと下段を合わせる
- 玉はタッチ、または左右にスライドして動かす。「たまを もどす」で最初の配置に戻る
- 1回目にまちがえたら、もう一度考えられる（2回まちがえると答えを表示）
- タイマー表示なし・じこベストには記録しない

## ② チャレンジモード
10問／20問、じこベスト記録、まちがえた問題の復習つき。

## ③ ぼうけんモード
- 6つの島（レベル1〜6に対応）を、1島4マス＋ボスで進むすごろく形式
- 1ステージ20問、15問以上正解でコマが1マス進む
- ボス戦：その島までの問題が混ざって出題。ハート3つ、早く答えるほど大ダメージ
- ボスの攻撃ゲージ：約8秒（くりあがり・くりさがりの島は約11秒）で満タンになると攻撃され、ハートが1つ減る。残り2秒で「くるぞ！」と予告
- バトル画面はRPG風（夜空色の背景・メッセージウィンドウで状況を表示）
- 最後のボスは全レベルの総復習

バッヂは全31こ（レベル・ぼうけん・とくべつ）。
記録とバッヂはその端末のブラウザに保存されます。
